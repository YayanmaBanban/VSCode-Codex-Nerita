# シンボル検索の待機方針

シンボル検索は VS Code の言語プロバイダーへ委ねる。プロジェクト設定ファイル、ソース拡張子、ディレクトリ名を Nerita 側で決め打ちして初期化する対応は、ユーザーの指示により外した。

`vscode.executeWorkspaceSymbolProvider` の検索結果が空でも、言語機能の準備中なのか、該当するシンボルがないのかは判別できない。短い間隔で再検索し、それでも空なら該当なしとして完了する。応答待ちの間は候補一覧に `LoaderCircle` を表示する。

言語プロバイダー自体が起動していない場合や、未読込のプロジェクトを対象に含めない言語拡張では、待機だけで候補が増えるとは限らない。対象言語の文書を一度も開いていない状態でも自動検索させるには、VS Code から汎用の準備状態・プロジェクト読込 API が得られるかを改めて調査する。特定言語の構成を推測する処理へ戻さない。
