この素案では、ChatGPT Pro を相談用ツールとして呼ぶ方式と、ChatGPT Web を Codex のモデルとして選ぶ方式を比較します。`codex-chatgpt-web` は後者の参考実装です。以下は素案作成時の調査・提案であり、このリポジトリの実装済み機能を示すものではありません。<!-- :chatgpt-content-reference{index="0"} -->

|                    | `codex-chatgpt-pro-plugin`           | `codex-chatgpt-web`                                    |
| ------------------ | ------------------------------------ | ------------------------------------------------------ |
| ChatGPT への接続   | ブラウザ自動操作                     | ブラウザ自動操作                                       |
| ブラウザ           | 外部 Chrome + CDP `:9222`            | **内蔵 Electron Browser**                              |
| Codex からの見え方 | `chatgpt-pro` を外部相談役として呼ぶ | **ChatGPT Web を Codex のモデルとして選択**            |
| コンテキスト       | プロンプトとして渡す                 | Codex の構築済みのタスク文脈を渡す                     |
| 応答               | CLI/tool の結果として返す            | **Responses API + SSE としてストリーム**               |
| ツール利用         | 基本は相談役                         | Full `mode` では Codex のツール実行基盤を MCP で逆接続 |
| セッション         | `repo/room` 中心                     | **Codex task ↔ Temporary Chat**                        |
| Chrome 依存        | あり                                 | なし                                                   |

`codex-chatgpt-pro-plugin` は、専用 Chrome プロファイルを `127.0.0.1:9222` の CDP で操作します。<!-- :chatgpt-content-reference{index="1"} -->

`codex-chatgpt-web` は次の構造です。

```text
Codex
  │
  │ Responses API
  ▼
codex-chatgpt-web daemon
  │
  │ browser automation
  ▼
Embedded Electron Browser
  │
  ▼
ChatGPT Web
```

Codex にはローカルの Responses 互換エンドポイントを見せて、その裏側で ChatGPT Web を操作しています。<!-- :chatgpt-content-reference{index="2"} -->

### VS Code 拡張で ChatGPT Web をモデルとして選ぶ案

ChatGPT Pro を相談用ツールとして呼ぶ方式は次のとおりです。

```text
Codex
   │
   └─ MCP: ask_chatgpt_pro()
              │
              ▼
          ChatGPT Web
```

この方式では、次のように役割を分担します。

> 「Codex はメインモデルのまま、ChatGPT Pro を相談役として呼ぶ」

ところが `codex-chatgpt-web` は、次の構成に近いものです。

```text
VS Code Chat UI

Model:
 ├─ Codex / Astra
 ├─ Codex / Sol
 └─ ChatGPT Web / Pro   ← これを直接選択
```

README でも、ChatGPT Web の Instant / Medium / High / Extra High / Pro を**Codex の標準のモデル選択欄から選択する**構成になっています。<!-- :chatgpt-content-reference{index="3"} -->

以前挙がった要望は次のとおりです。

> VSCode でも ChatGPT モードを使いたい

この要望には、**ChatGPT Web をモデルとして選べる構成**が適しています。

---

Full harness は、ChatGPT Web から Codex のツールを利用する仕組みです。

通常、ブラウザーで ChatGPT を開いただけでは、以下の機能を利用できません。

```text
ChatGPT Web
   × ワークスペースファイル
   × Terminal
   × Codex tool
```

`codex-chatgpt-web` では、ChatGPT Web から MCP 経由で Codex のツールを呼び出します。

```text
             ChatGPT Web
                  │
               MCP call
                  ▼
          OpenAI Tunnel
                  │
                  ▼
codex-chatgpt-web capability broker
                  │
                  ▼
              Codex task
              │   │   │
           files shell tools
```

この構成により、**ブラウザー上の ChatGPT Pro が、元の Codex タスクのファイル操作・シェル・ツール・承認機能を利用できます**。<!-- :chatgpt-content-reference{index="5"} -->

---

### VS Code 拡張への移植は必要な部分に絞る

素案作成時には、以下の構成を移植先の候補として検討しました。

```text
VSCode Extension
│
├─ UI / React
│
├─ ACP Client
│    └─ codex-acp
│
├─ Providers
│    ├─ CodexProvider
│    └─ ChatGPTWebProvider   ← NEW
│
└─ BrowserBridge
     └─ VSCode Integrated Browser
          └─ chatgpt.com
```

`codex-chatgpt-web` から参考にしたいのは次の部分です。

- Responses 互換ブリッジ
- Codex のタスク文脈を ChatGPT の一時チャットへ渡す処理
- タスク単位のブラウザーセッション
- モデルと推論レベルの対応付け
- SSE による逐次配信
- 圧縮時のセッション切り替え
- 応答と送信した質問の対応付け、ターン ID の検証

`codex-chatgpt-web` は表示順の `conversation-turn-N` ではなく、ChatGPT 側の `data-turn-id` を使います。「今回送信した質問に対する回答か」を追跡し、UI の再描画で古いメッセージを誤って取得することを防ぎます。<!-- :chatgpt-content-reference{index="6"} -->

---

モデルとして選ぶ方式と相談用ツールとして呼ぶ方式の、**2系統を持つ構成**を提案します。

```text
VS Code Extension
│
├─ Model Provider
│   │
│   ├─ Codex
│   │    Astra / Sol / ...
│   │
│   └─ ChatGPT Web
│        Instant
│        Medium
│        High
│        Extra High
│        Pro
│
└─ Tools
     │
     └─ ask_chatgpt_pro
```

この設計では、以下の両モードを提供できます。

#### ChatGPT モード

```text
ユーザー
 ↓
ChatGPT Pro
 ↓
回答・実装
```

#### Codex + ChatGPT レビュワーモード

```text
ユーザー
 ↓
Codex
 ↓
必要な時だけ
ask_chatgpt_pro
 ↓
ChatGPT Pro
 ↓
Codex
```

前者は `miuuyy/codex-chatgpt-web` 型、後者は `pauljunsukhan/codex-chatgpt-pro-plugin` 型です。

現在開発中の VS Code 拡張では、**同じ `ChatGPTWebBridge` を両モードで共有する設計**を提案します。

この素案で参照した時点では、`codex-chatgpt-web` は v5.0.8 まで更新されていました。ブラウザー DOM への追従やコンテキストの受け渡しについては、こちらを主要な参考実装とする案です。<!-- :chatgpt-content-reference{index="7"} -->
