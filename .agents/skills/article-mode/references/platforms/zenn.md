# Zenn アダプター

確認日 2026-11-19。[Zenn の Markdown 記法](https://zenn.dev/zenn/articles/markdown-guide)・[HTML/CSS 埋め込みの公式告知](https://info.zenn.dev/2026-11-11-html-embed)

1. 元の Markdown から閲覧用コピーを作る。媒体のタイトル欄または CLI の front matter に記事名を設定し、本文の見出しは `##` から始める。標準 Markdown のリンクとコードフェンスを維持する。
2. 長い修正前後などの補足だけを `:::details 修正前後のコメントとコードを見る` と `:::` で囲む。要約、適用条件、必須操作は外に残す。入れ子のコンテナが必要なら外側のコロンを増やす。本文内のコードフェンスと空行を保持する。
3. 図の位置に、検査済みの SVG をそのまま `html-embed` フェンスの中へ入れる。文書全体の HTML タグや外部依存を追加しない。図の題名と説明を SVG にもち、キャプションは本文に置く。1ブロック50 KB以内。表示の上限は高さ500 pxなので、スマホ幅でも内側スクロールが生じないよう収める。明暗双方で読める背景と前景を指定する。
4. プレビュー先で Beta 機能が図を描画しない場合は、対応する環境で確認する。画像へ切り替える場合は、同じ SVG から PNG を生成し、利用可能な画像パスまたは確認済み URL と代替テキストを使う。確認できた表示方式を記録する。

[公式の Zenn CLI](https://zenn.dev/zenn/articles/install-zenn-cli) を使う場合、隔離した作業ディレクトリで `npx zenn init` と `npx zenn new:article` を実行し、生成ファイルを `published: false` のまま閲覧用コピーで更新して `npx zenn preview` を開く。CLI が Beta に対応しているかをプレビューで確認する。

PC・スマホ幅で閉状態、展開後の修正前後・リスト・コード、リンク、開閉、コードのコピーを検証する。SVG はラベルが読め、元図と同じ関係が描画されるか確認する。プレビュー種別と版、画面幅、未確認項目を記録する。

承認構成に `detailPlan` がある場合は [折り畳みの表示照合](../folded-details.md) の ID を使い、初期閉パネルを媒体出力から確認する。

ローカル検証と公式サイト上の対象稿の確認を、原稿の版とともに記録する。公式サイトのプレビューを開いていなければ `liveZennPreview` は未確認とし、過去の版の表示結果はその版の記録として保存する。
