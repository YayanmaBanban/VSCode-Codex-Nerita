# チュートリアル

読者が作る結果、開始状態、対象 OS・ツールとバージョン、権限・依存関係を入力にする。

1. 完成状態と成功を判定する方法を先に示す。開始前に満たすべき条件、必要なファイルや設定、手順の副作用を整理する。
2. 構成案では、完成状態の見せ方や説明を挟む位置を変える。コマンドと設定の前後関係は全案で守る。構成承認後に、一つの実行経路として書く。
3. コピーできるコマンド、作業ディレクトリ、差し替える値、実行後に見える結果を示す。失敗を見分ける方法と安全な復旧手順を、対応する操作の近くに置く。必須のコマンドや注意事項は常時表示する。
4. 指定の開始状態から順番に実行し、各段階の出力と完成状態を照合する。試行できない手順は未確認と記録する。

前提、実行順序、コピー可能な操作、期待結果、復旧手順、制限と再現結果を出力する。
