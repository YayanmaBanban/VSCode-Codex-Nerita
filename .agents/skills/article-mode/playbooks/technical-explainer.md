# 技術解説

読者の疑問、前提知識、説明対象、適用する版や環境、調査済みの出典を入力にする。

1. 読者の疑問を一つの文で定め、公式資料・実装・再現結果から答えを確認する。確認できた条件と例外を整理する。
2. 構成案ごとに、先に示す答え、その答えが成立する条件、仕組みを説明する順序、具体例を決める。構成承認後に、冒頭で疑問と主要な答えを示す。
3. 仕組みは用語の定義から羅列せず、実際の入力や例を使って処理を追う。条件によって挙動が変わる箇所は本文で示す。
4. 説明・実例・図の順序を見直し、見出しだけで答えと適用範囲がわかるか確認する。実装や公式資料が主張を支えているか照合する。

課題と主要な答え、仕組み、適用条件、実例、出典がそろった記事を出力する。
