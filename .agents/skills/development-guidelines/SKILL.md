# 開発ガイドライン

対象リポジトリの指示と既存実装を確認し、作業に該当する規約を適用する。配置・実行コマンド・独自 API は対象プロジェクトの文書、パッケージ定義、設定から確認する。参照先が未指定なら関連する設定と利用側を調べ、別プロジェクトの構成を前提にしない。

## 作業に応じた参照

作業別リファレンスは、この表を唯一の入口として選ぶ。複数に該当する場合は組み合わせ、各リファレンスから参照される共通ルールも、作業に該当するものを読む。作業別リファレンス同士では参照を指示しない。

同じ作業内で確認済みのファイルは、複数の参照元がある場合も再読しない。ただし、内容が更新された場合は変更箇所を確認する。局所修正では全体の依存調査を行う必要はなく、文書のみの変更では UI レビューは不要。
