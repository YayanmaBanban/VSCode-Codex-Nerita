# Playbook selection

Source: pstack poteto-mode Playbooks section at `005d8f6e8ec057b738adcd08a08b30db0478402d`.

Match the task to a playbook and open its steps at `../playbooks/<title>.md`, with the title in kebab case. Copy its steps into the todolist tool first. Large, cross-cutting, or unattended work, or a task no playbook fits, routes to the **figure-it-out** skill.

Investigation, Bug fix, Perf issue, Hillclimb, Runtime forensics, Trace forensics, Feature, Refactoring, Prototype, Visual parity, Authoring a skill, Eval, Babysit, Shipping, Autonomous run, Autopilot-full, Autopilot-stack, Session pickup, Pause safely, Multi-phase plan, Worktree cleanup, Opening a PR.

## ToDo expansion

For a multi-step task, make the first ToDo a review of the full `references/principles.md` index, then copy **each step of the selected Playbook** into the ToDo before task-specific steps. Keep numbered steps and nested checkpoints (for example the four Feature Throughput Checkpoint items). If a step cannot be performed in Pi/Codex, keep it visible and report what blocked it; the permission or compatibility rules decide whether proceeding is safe.
