# 翻訳・逆訳の整合性確認

対象：saji PRの日本語化。比較元はpstackの固定コミット`005d8f6e8ec057b738adcd08a08b30db0478402d`。翻訳前のsaji初期版（`3b47a25a8a828bcf0654b0024390e8b387833a5c`）も照合に用いた。

## 確認方法

1. **構造の照合。** 各Playbookの番号付き工程と入れ子の箇条書き、各Principleの箇条書き、コードブロックを原文と比較する。
2. **技術識別子の照合。** コマンド、ファイルパス、コード文字列、モデルプレースホルダー、数値、ステータス値を照合する。原文の固有モデル識別子は事前合意した互換性変更の対象。
3. **意味の逆訳。** 日本語の必須条件・禁止条件・例外・因果関係・実行順序を英語の技術的な命題として読み戻し、原文が要求する振る舞いと比較する。語順や表現の一致ではなく、成立条件と禁止される行動の一致を評価する。
4. **意図的な変更との分離。** 原文からの互換性変更は翻訳ミスと混同せず、`UPSTREAM.md`と`references/compatibility.md`で扱う。

これは機械的な逐語対訳の証明ではない。実際のPi/Codexでの動作検証とも別である。

## 構造の確認結果

- Playbook **22件**の番号付き工程数は、翻訳前後で全件一致した。Perf issueの7項目の改善順序、Featureの4項目のThroughput Checkpoint、Hillclimbの1反復に含まれる4項目など、入れ子の項目数も一致した。
- Principle **24件**の箇条書き項目数は、翻訳前後で全件一致した。原文のfrontmatterにしかない適用条件は、日本語の適用条件一覧または本文へ引き継いだ。
- Inline codeや固定識別子は照合した。意図的なモデル置換を除き、失われていた`<root>`と`##`の表記を補正した。
- Babysitから参照される`references/bugbot-triage.md`は、未収録の依存先だったため原文から日本語化して追加した。

## 逆訳で確認した重要な条件

| 対象 | 日本語から読み戻して原文と照合した技術的条件 |
| --- | --- |

| Bug fix | 実環境で再現し、仮説を二分探索し、故障の仕組みを証拠で確定してから設計・修正する。失敗する再現ケースが修正より先に履歴へ入る |

| Refactoring | 変更前に振る舞いの契約を固定し、構造変更中も維持する。旧APIの互換経路を残さず、実物で同等性を証明する |

| Worktree cleanup | 未コミット変更と使用中のworktreeは削除しない。監査の`safe`判定より、ピン留めや実際の利用状況を優先する |
| Principle群 | 不正状態の型による抑制、境界での検証、共有状態の事前分離、実物での確認、挙動を基準にしたテストなどの前提・例外を維持した |

## 翻訳後に修正した表現

- Pause safelyのPR/Pushに関する例外を、単に「作業に着手していた場合」ではなく「公開済みのPRやPush先がある場合」と明示し直した。
- Opening a PRの呼び出し時点を、曖昧な「終盤」から原文どおりの「終了時」に直した。
- Worktree cleanupの`<root>`と、PR本文の`##`見出しを補足した。
- Evalの軽量担当モデルは固定名を維持せず、`<role-model>`へ置換した。これは翻訳ではなく合意済みの環境適合である。

## 原文から意図的に変えている部分

- **操作権限：** 原文の自律的なコミット・Push・マージ指示は、ユーザーの明示的な許可を要するルールへ置換した。Playbook内の原文指示より`references/autonomy.md`が優先する。
- **実行環境：** Cursor固有のモデルslug、Task引数、外部プラグイン、クラウドエージェント、`/loop`などは利用できるホスト機能へ読み替える。未対応なら実行済みとは扱わない。
- **Skill分割：** `poteto-mode`の各セクションを独立した参照文書へ分けた。Principleの適用条件とPlaybookの工程は残した。
- **ライセンス：** 法的に必要な英語原文`LICENSE.pstack`を保持し、`LICENSE.pstack.ja.md`に非公式参考訳を設けた。

## 限界と次の検証

日本語の記述と英語原文の技術的条件に、今回の照合で意図しない差は確認されなかった。ただし、この確認は完全な形式的同値性の証明ではない。外部の専門Skill本体とCursor Team Kitは未収録であり、Pi/Codexでの実際のPlaybook選択、ToDo展開、委譲、検証フローの通し実行は**未検証**である。
