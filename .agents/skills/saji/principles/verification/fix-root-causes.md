# 根本原因を直す（Fix Root Causes）

問題が表面化した場所ではなく、故障を修正する。根本原因とは、システムが最初に行ってはならない動作をした場所、または扱うべき状態を初めて扱えなかった場所である。

- 最初に再現する。コード上の誤った判断に行き着くまで「なぜ」を問い続ける。行き詰まったら計測を追加し、実際の状態を読む。
- 症状を起こした状態が正当なものか確認する。正当ならコードが壊れた箇所で扱う。本来存在してはならない状態なら、その場のチェックはバグを隠すだけなので、その状態を作った箇所を探す。ガード、再試行、握りつぶしたエラー、値の丸め込み、状態の破棄はバグを隠しやすい。
- 個別の発生箇所ではなくパターンを修正する。同じ故障を持つすべての箇所を調べる。
- 判断に必要な事実を深く調査してようやく得られたなら、最初の確認で見つけられたはずの、安価で常時利用できるシグナルを提案する。
